# Hospital Management System

This is a full-stack hospital management system project with:

- Frontend: React with Tailwind CSS, Google Fonts, Font Awesome
- Backend: Node.js with Express.js and PostgreSQL database

## Features

- Patient management (registration, records)
- Doctor management (profiles, schedules)
- Appointment scheduling
- Basic user authentication (admin, doctor, receptionist roles)
- Billing overview

## Project Structure

- /frontend: React app with components for patients, doctors, appointments, authentication
- /backend: Express server with REST API endpoints for each feature, PostgreSQL database connection

## Setup Instructions

1. Setup PostgreSQL database and run migrations
2. Install dependencies for frontend and backend
3. Run and test the full application locally
